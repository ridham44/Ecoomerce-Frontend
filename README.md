# Exclusive Ecommerce Website Navigation Guide

This guide explains how to move through the live Exclusive ecommerce website and how to access pages that require login.

## Default Login

Some pages, like Wishlist and Cart, require login.

Use this default account:

```text
Email: alicapatel@gmail.com
Password: Aica44$
```

To log in:

1. Click `Log In` or open the login page.
2. Use the default email and password above.
3. After login, you can open protected pages like Wishlist and Cart.

## Main Navigation

The website has a header at the top with links and icons.

### Home

Click `Home` in the header.

On the home page you can view:

- Main hero banner
- Flash Sales products
- Live countdown timer
- Categories
- Best Selling Products
- Speaker offer section
- Explore Products
- New Arrival section

## Product Detail Page

To open the Audemars Piguet watch detail page:

1. Go to the home page.
2. Scroll to the `Flash Sales` section.
3. Click the Audemars Piguet watch image, product title, or eye icon.

On the product detail page you can:

- Switch between silver and gold watch colors
- Click thumbnail images to change the main product image
- Select a size
- Increase or decrease quantity
- Click the heart button to add/remove from wishlist visually
- View delivery and return information
- See related products below

## Contact Page

Click `Contact` in the header.

The contact page includes:

- Call information
- Email/support information
- Contact form with name, email, phone, and message fields

## About Page

Click `About` in the header to view information about the website/company.

## Sign Up Page

Click `Sign Up` in the header.

This opens the account creation page. The form is for demo UI navigation.

## Wishlist Page

Click the heart icon in the header.

Important:

- Wishlist is a protected page.
- If you are not logged in, the website will redirect you to the login page.
- Log in using the default account:

```text
Email: alicapatel@gmail.com
Password: Aica44$
```

After login, the website will take you back to the Wishlist page.

## Cart Page

Click the cart icon in the header.

Important:

- Cart is a protected page.
- If you are not logged in, the website will redirect you to the login page.
- Use the same default login details.

After login, you can view the cart page.

## Checkout Page

Open the cart page first, then continue to checkout from the cart flow.

Checkout path:

```text
/cart/checkout
```

This page is also protected, so login is required.

## Account Page

After login, click the account/user icon in the header.

The account menu includes account-related navigation such as:

- Manage My Account
- My Order
- My Cancellations
- My Reviews
- Logout

## Search Bar

The search input is in the header. It is currently a demo UI element for layout and navigation.

## 404 Page

If you open a page that does not exist, the website shows a custom `404 Not Found` page.

Use the `Back to home page` button to return to the home page.
